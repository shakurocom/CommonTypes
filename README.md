# CommonTypes

## Installation

### Swift Package Manager

Add the package to the `dependencies` of your `Package.swift`:

```swift
.package(url: "https://github.com/shakurocom/CommonTypes.git", from: "1.9.6")
```

and the product to your target:

```swift
.product(name: "CommonTypes", package: "CommonTypes")
```

In Xcode, use File > Add Package Dependencies… with `https://github.com/shakurocom/CommonTypes.git`.
With SPM the module is `CommonTypes` (`import CommonTypes`); with CocoaPods it is `Shakuro_CommonTypes`.

### CocoaPods

```ruby
pod 'Shakuro.CommonTypes'
```
